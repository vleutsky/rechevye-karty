# Память проекта — речевые карты Крупенчук

## Для кого
Сайт для одного логопеда (Наталья). Пароль и несколько пользователей пока не нужны.

## Задача
Удобно заполнять речевые карты О. И. Крупенчук на 4, 5 и 6 лет.
Печать должна быть как в исходных Word-файлах.

Исходники:
- `Речевая карта Крупенчук. 4 года.docx`
- `Речевая карта Крупенчук. 5 лет.docx`
- `Речевая карта Крупенчук. 6 лет.docx`

Разобранный текст лежит в `_source/`.

## Как устроено
- Статический сайт, без сборки. Данные детей и обследований — в браузере (localStorage).
- Облачная синхронизация (с 2026-10-13, по просьбе владельца): кнопка «Облако», кабинет по почте и паролю. База автоматически сохраняется на наш хостинг (api/index.php, данные вне public_html) и подтягивается на каждом устройстве при открытии. Конфликты — по времени сохранения (savedAt). Сервер хранит автобэкапы.
- Можно выгрузить и загрузить JSON-копию вручную («Копия» / «Загрузить копию»).
- Три вида карт: речевые Крупенчук (4/5/6 лет), ВПФ Павловой–Руденко (3-4…6-7), мониторинг речи Розовой (1-4 класс).
- Заполнение по разделам, печать на A4.

## Правила работы
- Интерфейс только на русском.
- Формулировки полей — как в исходных методиках (Крупенчук, Павлова–Руденко, Розова), не выдумывать разделы.
- Персональные данные детей передаются только на наш хостинг по HTTPS (облако) и в файлы копий; больше никуда их не отправлять.
- Не усложнять: без сборки, без фреймворков.
- Печатная версия — главный документ, экранная форма под неё.

## Как открыть
Локально: файл `index.html` в браузере (лучше Chrome или Edge).
В интернете: GitHub Pages, адрес появится после публикации репозитория.

Кнопка «Файл базы» (Chrome/Edge на компьютере): создать или открыть JSON-файл на ПК, дальше каждое изменение сразу пишется в него. Сайт помнит файл (IndexedDB); после перезапуска браузера может попросить «Подключить базу» — одно нажатие. localStorage остаётся кэшем, при подключении берутся более свежие данные (по savedAt).
Кнопка «Копия» сохраняет JSON на компьютер. «Загрузить копию» возвращает данные.
Данные детей живут в браузере конкретного устройства. На другом телефоне или компьютере список будет пустой, пока не загрузите копию.

В git не класть `_source/`, `dist/`, `.netlify/`.

## Не делать без просьбы
- Несколько пользователей с разными правами.
- Автоматическое логопедическое заключение «за логопеда».
- Публикацию данных куда-либо, кроме нашего хостинга.
